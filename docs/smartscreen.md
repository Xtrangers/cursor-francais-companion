# SmartScreen et signature (P7-06)

Aucun certificat Authenticode n’est configuré dans ce dépôt (budget 0 €).

Les binaires **ne sont pas signés**. Windows peut afficher :

> Windows a protégé votre ordinateur — SmartScreen

## Que faire

1. Vérifier que le zip vient du repo `Xtrangers/cursor-francais-companion`.
2. Propriétés du `.exe` → débloquer si besoin.
3. Pour une signature : fournir un certificat, puis relancer le script de packaging.

Ne jamais acheter un certificat sans accord (règle 38).
